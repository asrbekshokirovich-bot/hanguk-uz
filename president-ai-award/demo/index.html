How it works

Not a recorder. An understanding memory.

Five stages turn a lived day into an answerable memory — the same arc the President AI Award's own 5-stage program takes a startup on: prototype to investment-ready.

01
🎙️

Capture

On-device, consented listening with a visible indicator and one-tap pause.

02
📝

Transcribe

Uzbek/Russian/English speech-to-text, including natural code-switching.

03
👥

Identify

Speaker diarization — patient vs. doctor vs. family member.

04
🧠

Remember

Each moment embedded into a private semantic memory of events, people & meds.

05
💬

Recall

Ask anything; an LLM answers from memory and cites the exact moment.

Privacy is the product

A device that hears everything must be trusted with everything.

Trust isn't bolted on at the end — it's the foundation that makes an always-available memory acceptable for a vulnerable user.

  • ✓ Consent + visible recording indicator, one-tap pause
  • ✓ On-device pre-filtering before anything is uploaded
  • ✓ Encryption in transit and at rest
  • ✓ Data stored in Uzbekistan — sovereign by design
  • ✓ User & caregiver control: view, export, delete any memory
  • ✓ Clear third-party consent signaling
