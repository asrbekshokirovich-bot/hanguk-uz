Login va build
muammolarini tuzatish

Google ilovaga kira olmagani uchun uni rad etdi. Quyida sababning aniq zanjiri va uni tuzatishning har bir qadami — nusxa ko'chirib qo'yiladigan kod bilan. Qadamlar tartib bilan bajarilishi kerak: A blok ilovaga kirishni tiklaydi, B blok esa build'ni Play qabul qiladigan holatga keltiradi.

Boshlashdan oldin

Bu qo'llanma faqat login va build'ni qamrab oladi. Repodagi ochiq kalitlar masalasi alohida qoldi — u hal qilinmaguncha ilovani do'konda saqlab turish xavfli. Bunga commit qilingan keystore ham kiradi: android/app/upload-keystore.jks (repo ildizida, Capacitor tomonida) hozir git tarixida turibdi; KAKAO_JS_KEY ning default qiymati ham kodga yozilgan (app_config.dart:64). Login ishlagach bularga qayting.

DiagnozNima uchun buzilgan

Skrinshotdagi "Unexpected server error. Please try again, or contact your counsellor." matni butun kod bazasida faqat bitta joyda uchraydi:

Asosiy xulosa

Agar QR6ZUBDZ kodi noto'g'ri bo'lganda, reviewer "We don't recognise this code" ni ko'rar edi. U buni ko'rmadi. Demak muammo kodning o'zida emas — server javob bermayapti yoki topilmayapti.

Xato qanday "INTERNAL_ERROR" ga aylanadi

Dart tomonidagi catch blokiga qarang. Server 404 qaytarganda javob tanasi {"code":404,"message":"Requested function was not found"} bo'ladi — bu Map, lekin uning ichida error kaliti yo'q. Shuning uchun shart bajarilmaydi va kod pastdagi umumiy holatga tushadi:

Funksiya deploy qilinmagan — tashxis tasdiqlandi

Bu asosiy sabab. Ilova mavjud bo'lmagan endpointni chaqirmoqda, gateway 404 qaytarmoqda, Dart uni INTERNAL_ERROR ga aylantirmoqda.

Bajaring: L1 → L2 → L3 → L4, keyin bu testni qayta ishga tushiring. Javob 401 CODE_NOT_FOUND ga o'zgarishi kerak.

Funksiya ishlayapti — muammo kodda yoki bazada

Server sog'lom. Demak reviewer bergan QR6ZUBDZ kodi bazada topilmagan, yoki reviewer test paytida server vaqtincha o'chgan.

Bajaring: L6 (xato xabarlarini aniqlashtirish) va L7 (Google uchun doimiy demo hisob). L1–L4 ni ham bajaring — ular kelajakdagi noto'g'ri deploy'ning oldini oladi.

Funksiya bor, lekin ichida yiqilyapti

detail maydonini o'qing — u aniq sababni aytadi. Agar u supabaseKey is required yoki shunga o'xshash bo'lsa, SUPABASE_ANON_KEY yetishmayapti.

Bajaring: L4 (Secrets tekshirish) va L5 (env himoyasini qo'shish). Keyin L6.

Aniq bo'lmagan xato

Supabase Dashboard → Edge Functions → student-login-v2 → Logs ni oching. Funksiya logEvent() orqali har bir so'rov uchun bitta JSON qator yozadi. Agar log'da hech narsa yo'q bo'lsa — so'rov funksiyaga umuman yetib bormagan, ya'ni u deploy qilinmagan.

2-o'zgarish — catch bloki HTTP statusni ajratsin

Bu asosiy tuzatish. Hozir 404, 500 va tarmoq uzilishi — hammasi bitta xabarga aylanadi. Endi ular ajraladi:

auth_repository.dart — signInWithMagicCode() catch bloklari
} on FunctionException catch (e) {
  // Funksiya tipli xato qaytardimi? Unda uni to'g'ridan-to'g'ri ko'rsatamiz.
  if (e.details is Map) {
    final m = e.details as Map;
    if (m['error'] != null) {
      return (
        error: _messageFor(m['error'].toString(), m['detail']?.toString()),
        studentName: null,
      );
    }
  }

  // Tipli xato emas — demak gateway darajasidagi muammo.
  // 404 = funksiya deploy qilinmagan. Buni ALOHIDA ko'rsatamiz,
  // aks holda u "Unexpected server error" ichida yo'qoladi.
  final status = e.status;
  if (status == 404) {
    return (
      error: _messageFor('SERVICE_UNAVAILABLE', 'login endpoint not found'),
      studentName: null,
    );
  }
  if (status >= 500) {
    return (
      error: _messageFor('SERVICE_UNAVAILABLE', 'HTTP $status'),
      studentName: null,
    );
  }
  return (
    error: _messageFor('INTERNAL_ERROR', 'HTTP $status'),
    studentName: null,
  );
} on AuthException catch (e) {
  return (
    error: _messageFor('AUTH_SIGNIN_FAILED', e.message),
    studentName: null,
  );
} catch (e) {
  // Tarmoq uzilishi va JSON parse xatolari shu yerga tushadi.
  final text = e.toString();
  final isNetwork = text.contains('SocketException') ||
                    text.contains('ClientException') ||
                    text.contains('Connection') ||
                    text.contains('TimeoutException');
  return (
    error: _messageFor(isNetwork ? 'NETWORK_ERROR' : 'INTERNAL_ERROR', text),
    studentName: null,
  );
}
