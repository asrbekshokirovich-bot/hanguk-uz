# Google Play sahifasi matnlari (reja R6.1)

Play Console → Store presence → Main store listing → **Manage translations**
ga shu papkalardagi matnlar qo'yiladi (yoki `fastlane supply --skip_upload_apk`).

- `title.txt` ≤ 30, `short_description.txt` ≤ 80, `full_description.txt` ≤ 4000 belgi.
- Google Play'da **o'zbek tili yo'q** (qo'llab-quvvatlanadigan tillar ro'yxatida emas) —
  shuning uchun en-US (asosiy), ru-RU, ko-KR, vi, ky-KG (Qirg'iziston, KG8).
- Raqam va foiz yo'q; ehtimollar «taxminiy, kafolat emas» deb yozilgan.
